## Direction

The UI should feel like a premium training operating system, not a generic member portal.

Core traits:
- cinematic dark surfaces
- neon-green focus states
- angular/athletic typography
- compact labels
- high information density
- strong imagery and video
- clear hierarchy
- subtle green glow
- app-like mobile treatment

When a visual reference is available, match it closely before inventing alternative styling.
